What is concrete
----------------
joint_parent.py authenticates one immutable 17-field root case and this source
manifest. It takes one exclusive GPU0 flock, snapshots the two selected frozen
checkpoints, then starts exactly four known evaluator Popen handles. Each uses
a distinct port and output directory, with the same 16 logical slots4096..4111.
Compilation and all-shape/serving-thread warmup happen serially before a shared
start command. Four connected/boundary-ready populations precede one immutable
admit command. Admission start skew must be <=1s; the original 2400s admission
and 3600s whole-cohort timeout are not extended or reset. The parent also uses
the shared start+3600s deadline, a slightly stricter common upper bound.

joint_member.py reuses the pinned continuous-guard evaluator's unchanged Job,
private environment/boot assets, compiled FP32 actor, protocol/source checks,
exact helper installation, owned PrivateFleet and cleanup primitives. It keeps
serving all16 original actors after its own cohort closes. New games starting
after close are unscored; all original admitted tails remain included. During
padding, protocol, guard, actors, boundary, frozen clocks/replay and timeout
logs remain checked. Any padding fault invalidates the whole joint campaign.
An early stop cannot close a member successfully.

Each full job (including its own port) is validated against its own plan using
the existing load_leg. Only port is excluded from cross-member scientific
signature equality; it is not ignored at the individual boundary. All16 slots
and at least50 original full games are required per member. The existing
fresh-reference arithmetic limb is copied verbatim: pool R1+R2 only; compare
each C separately against >=1.05 mean and >=reference median. No candidate
pool rescue, truncation, retry, admission extension or automatic promotion.
A/A mode uses the same checkpoint four times and can never qualify/promote.

Dedicated future carrier and lifetime lease
------------------------------------------
Bare-process execution is refused. The selected user systemd unit must be a
dedicated cgroup containing only this parent initially, with Type=exec,
Restart=no, RemainAfterExit=yes, KillMode=control-group, KillSignal=SIGINT,
TimeoutStopSec=240s and SendSIGKILL=yes. Its actual argv must bind this source,
case SHA and manifest SHA. Parent CPU affinity must match the explicit case
mask and exclude the unchanged main inference mask. Root must precommit actual
CPU/memory/task/whole-unit runtime bounds and validate installed systemd
semantics before selection; this packet does not create or stop any unit.

The SAME open-description flock FD is passed with pass_fds into every member
and every owned MAME Popen. Members check the inode/owner and WRITE FLOCK fdinfo
in themselves and all16 MAME processes while serving. No holder calls LOCK_UN.
Separate sessions do not change cgroups. A failure to retain this descriptor
is invalid, not a weaker lease mode. Compile descendants may close extra FDs;
they still must remain inside the dedicated cgroup, which must contain only
parent before normal0. No promise is made that a dead parent alone holds a
lease. Surviving member/actor holders retain the same description until their
owned cleanup/systemd cgroup cleanup closes it. Actual MAME inheritance and
fault cleanup have NOT been tested here.

Parent requests one bounded cleanup of its exact original handles. A timeout,
missing closure, surviving descendant or foreign identity means native failure.
There is no wildcard kill, retry, arbitrary PID cleanup or external keeper.
Systemd supplies the precommitted cgroup stop/KILL bound on failure. Outside
root must preserve original native exit/ExecMainPID/invocation and all six raw
commands BEFORE timer-first owned release. RemainAfterExit=yes preserves the
descriptor. Root must verify cgroup, GPU0 owners and all four ports empty after
parent death and before any lease/resource reuse; CUDA teardown may lag FD
closure. Parent output is not that external release proof. Actual failure-path
systemd validation remains mandatory before A/A selection.
