Execution contract

Only display GPU0 UUID GPU-b549355c-78bb-53d8-04a6-da34d45e1dd0 is visible. The
main GPU UUID GPU-c0c5d295-6f07-aab5-bbde-b592ea426ec1 is excluded. The parent
requires exactly one existing main-GPU owner and preserves its PID/start identity;
it refuses quality/sidecar/benchmark/affinity windows, IPv4/IPv6 port9999 listeners,
or foreign GPU0 compute owners. Linux /proc socket inspection avoids making a
probe connection to a live evaluator. Guards are rechecked between phases with
one-second polling while a child runs; each NVIDIA query has a five-second
timeout. The smoke lease does not serialize uncooperative
external launchers; parent scheduling ownership remains required.

The parent verifies snapshot patch/base/staged hashes, copies the complete dqn
package/C source into private output, and checks child imports stay there. Each
phase has distinct private MODEL_DIR/control/settings/journal/cache paths and
an existing nonce tmpfs directory assigned to cfg.replay_tmpfs_dir BEFORE actual
agent construction. MODEL_DIR alone would share the live tmpfs basename.
No production checkpoint, replay mapping, runtime control or state sample is read.

The child waits for its parent token BEFORE inspecting cgroup membership; the
parent attaches it before releasing the token. All ownership/source/environment,
cgroup and live guards precede numerical imports. Worker parent-death SIGKILL is
armed with Linux prctl; handled INT/TERM/HUP in the parent drain only its owned
process group/cgroup, with signals blocked through cleanup. The child
unblocks the inherited launch signal mask after verifying its parent, so normal
TERM handling remains available in the worker. A pre-identity acquisition
failure closes its token pipe and terminates/reaps that exact unreaped Popen
child. SIGKILL, kernel failure or machine loss can leave private files/cgroup
bookkeeping; no aggregate PASS is published before owned cleanup completes.

Bounds: worker cgroup 12GiB RAM/no swap, 2 CPU cores, 96 tasks; CUDA allocator
10GiB plus a monitored 11GiB process allowance; total300s/phase140s; output4GiB
and private tmpfs128MiB. Storage bounds use fixed tiny geometry and a cooperative
byte watcher, not a filesystem quota. The outer unit is bounded separately.

The capture child constructs actual full 11128-state Rainbow networks, enabled
CUDA AMP/scaler and fused Adam (fallback rejected), real prefetch and an actual
SocketServer on an ephemeral loopback port with no clients. The constructor's
learner is joined before manually bounded updates. A wrapped128-row synthetic
ring and both64-row elite episodes pass through real FIFO/admission/save paths.
At most3 pre-capture attempts must produce an actual Adam step/nonzero moments
and changed, finite weights. Only a positively classified AMP skip may consume
a retry. It requires one supported immediate optimizer-exposure skip, zero
applied/unavailable outcomes, every Adam parameter step unchanged, online state
and nonzero Adam moments unchanged, a finite decreased scale, and finite
online/target/inference/optimizer/scaler state. Missing lazy Adam slots and newly
allocated all-zero step0/moments are equivalent. Applied updates require finite
gradients/reported norm, nonregressing per-parameter Adam step advancement and
changed online state. Unavailable outcomes, train exceptions, missing/nonfinite
losses or other nonfinite state fail. The restore phase still requires its
single further update to apply.

Each attempt fsyncs optimizer-attempts.jsonl before training, after immediate
observations and BEFORE classification, and after classification/rejection.
Nonfinite values are retained as explicit strings. Diagnostics include all
per-parameter Adam steps, online/nonzero-moment hashes, scale, actual process-local
exposure identity/counters, finite checks, loss/norm/clocks and effective runtime
Python/Torch/CUDA/GIL/expert availability. These checks do not change scaler
initialization, learning settings, training sources or the attempt limit.

Snapshot capture must certify the real device barrier, parked
accept gate, unchanged guards/files and restored paused flags.

After capture child exit, a fresh restore child uses copied archive/ring/banks
at constructor-correct private paths. Actual load must restore all saved tensors,
Adam/scaler, clocks/policy controls, replay metadata/fields/priorities and bank
contents/ages. Runtime/manual LR/settings are applied explicitly. One further
real fused/AMP update must apply and archive hashes must remain unchanged.
Process-local replay counters/epochs reset; RNG and actor/game state are not
restored. The harness makes no deterministic continuation or performance claim.
