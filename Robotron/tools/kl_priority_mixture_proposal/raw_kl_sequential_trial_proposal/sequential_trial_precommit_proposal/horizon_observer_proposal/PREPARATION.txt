only, at most3602 polls plus one poll-budget-exhaustion receipt. Root callbacks must
have their own short deadlines; synchronous Python cannot enforce wall deadlines
while a callback blocks. Root watchdog/owned cleanup, not this helper, enforces
physical termination. API exceptions become missing observations; owner/evidence
exceptions become INVALID. Clock, sleep, interrupt and persistence errors propagate
for root cleanup; never restart this observer to search for a favorable candidate.
Root emit must persist each summary append-only/create-only and durably persist the
full LATCH before returning. No receipt writer is provided here. Required bound:
32MiB cumulative journal, at most3603 emitted records,2MiB raw API and64KiB evidence
per call. The helper retains the job, current+last valid raw API and first terminal
only; it does not retain the polling history. Terminal invalid/incomplete retains
one bounded terminal API (or last valid if none). LATCH includes the full eligible
API; summaries before it include scalar counts. APIs may carry unrelated NaN grad
norm on a known AMP skip; required counters/times are finite separately, and raw
NaN is preserved rather than converted to0. Root JSON writer must preserve that
observed representation or label a publication failure, never invent finite data.
