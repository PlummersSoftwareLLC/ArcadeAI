Exact acquisition boundary and ownership
---------------------------------------
Count FIRST EIGHT CONSUMED train_step attempts AFTER enabled/replay-pressure/
minimum-replay/batch guards, BEFORE transfer/wait_on_current_stream. This clock
is distinct from optimizer attempts/admissions/applied counters. Transfer,
forward, nonfinite-loss, optimizer, readback, priority or later learner failures

Outcome evidence and observer-fault containment
----------------------------------------------
The existing optimizer exposure finish runs first, using its real packed
found_inf readback. Only then does the observer record that mode/host value,
actual owner/epoch/finished ticket and before/after exposure deltas. Exactly one
recorded same-owner/same-epoch available outcome is required. AMP skips remain
recorded and follow the unchanged CE priority update. An already known outcome
survives a later learner/priority/storage failure; that attempt is still invalid
or incomplete. 'Applied_admission' is only the existing counter's scope, never
proof of parameter movement/Adam step advancement. Private no-step checks and
mock counter injections do not validate actual applied optimizer behavior.

Observer failures are caught only around observer operations. Replay metadata
copy failures are marked inside the SAME original draw, with a preallocated
error key, before returning its original batch. Post-draw small-field failures
are isolated likewise. No resample or whole-sampler suppression. A real sampler
exception is globally noted and re-raised unchanged before consumption. Session
locks, logging/formatting, file writes and device copies stay outside replay.lock.
Producer-side observer errors do not falsely attach to a different consumer row.
Public training observer hooks cannot leak ordinary observer faults into the
compile-disable/fallback handler. Missing observer-only kernel output invalidates
the trace while retaining usable first four CE outputs. Real kernel failures
still use the original learner path; current CUDA parity remains a blocker.

Faults latch bounded in-memory errors, incomplete status and best-effort console
diagnostics. Disk-full/reporting failure cannot stop CE; a preallocated reporting
failure flag prevents later complete status. Startup creation errors are fatal
before training threads, rather than silently disabling an enabled trace. Severe
process termination/OOM/filesystem failure can prevent durable diagnostics; no
crash-exact continuation, complete snapshot or automatic recovery is promised.

Storage: at most64MiB copied loss tensors, bounded4096-row draw metadata for the
eight rows and fixed producer slots (plus transient local overlap), and128MiB
conservative cumulative observer writes. No full-state/ring copy or asynchronous
writer is introduced. Files are context/status JSON plus create-only per-attempt
NPZ/JSON. They are observations, not a model/replay/optimizer recovery anchor.
The temporary copy/sync/write overhead alters timing and must not be sold as an
unperturbed throughput or quality measurement.
