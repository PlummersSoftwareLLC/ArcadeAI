# Recovered experiment source

These source files were created inside the ignored Robotron logs tree during
learning optimization and recovery work. They are preserved here before the
GB300 is returned. The manifest records original paths and SHA-256 hashes.
Generated Torch caches, virtual environments, logs, models, and replay arrays
are excluded. Repeated source snapshots are retained at their original relative
paths so their provenance remains visible.

This is an archive, not an executable deployment. It contains absolute historical
paths, pinned metadata dependencies, single-use jobs, and superseded proposals.
Do not run old jobs or restart old systemd overrides. Use Robotron/MIGRATION.md
for a fresh manual installation; create fresh runtime jobs before any future
controlled training or evaluation.
